# Stack Frontend — S01-FE-01

## Tecnologías principales

- React
- Vite
- JavaScript
- React Router
- Context API para manejo de estado
- Axios para consumo de API
- CSS / Tailwind CSS según definición visual del proyecto

## Estructura inicial

src/
├── assets/
├── components/
├── context/
├── pages/
├── services/
├── App.jsx
└── main.jsx

## Organización

### components/

Contendrá componentes reutilizables de la interfaz.

Componentes iniciales:

- Button
- Header
- Footer
- ProductCard
- RestaurantCard
- Layout

### pages/

Contendrá las páginas asociadas a las rutas principales de la aplicación.

Páginas iniciales:

- Home
- Productos
- Restaurantes
- DetalleProducto
- DetalleRestaurante
- Carrito
- Login

### services/

Contendrá la lógica relacionada con el consumo de servicios y API.

### context/

Contendrá los contextos globales de la aplicación, inicialmente orientados al manejo del carrito.

## Estado del documento
